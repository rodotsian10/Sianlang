# SianLang 0.5.1 스프라이트 저장 규칙

0.5.1은 스프라이트의 **파일 저장**과 **장면 사이 임시 상태 유지**를 분리합니다. 기본 장면 문법과 게임 명령은 [게임 API](../docs/game-api.md)를 참고하세요. [0.5.0 초안](../history/설명서/0.5.0-계획.md)은 당시 설계 기록입니다.

| 문법 | 역할 | 파일 변경 |
| --- | --- | --- |
| `rodot.create("image.png", "player.rodot")` | PNG를 rodot으로 변환 | 새 파일 생성 |
| `rodot.load("player.rodot")` | 스프라이트 불러오기 | 없음 |
| `player.x = 100` | 게임 중 스프라이트 값 변경 | 없음 |
| `Frodot player` | 블록의 `r.data` 변경을 자동 저장 | JSON 수정 |
| `rodot.save = true` | 다음 장면까지 변경값을 메모리에 유지 | 없음 |
| `rodot.save = false` | 다음 장면의 재로드 때 파일값 사용 | 없음 |

`rodot.save`는 불리언 설정이며 기본값은 `false`입니다. `true`일 때 장면이 바뀌면 현재 장면의 스프라이트 상태를 보관합니다. 다음 장면에서 **같은 변수 이름과 파일 경로**로 `rodot.load`해야 이어받습니다. 같은 파일을 `player`와 `target`으로 각각 불러와도 상태는 섞이지 않습니다. `false`로 전환한 뒤 장면이 바뀌면 저장해 둔 상태를 버립니다. 설정값은 게임 중 유지되며 종료 시 기본값으로 돌아갑니다.

```sian
rodot.save = true
game.start("main")

scene main
    var player = rodot.load("player.rodot")
    player.x = 100
    scene.change("play")

scene play
    var player = rodot.load("player.rodot")
    log player.x
```

`Frodot` 안에서는 `replace r.data.x = 100`, `add r.data.user.hp = 10`, `delete r.data.user.old_item`처럼 씁니다. 블록이 정상 종료하면 현재 스프라이트의 JSON을 원본 `.rodot`에 씁니다. 실패하거나 블록 안에서 장면을 바꾸거나 게임을 닫으면 저장하지 않습니다. 기존 `rodot.save(player)` 함수는 제거되었습니다.

`scene main`은 일반 장면과 똑같이 매 프레임 실행됩니다. 위처럼 `scene.change("play")`를 호출하면 다음 장면으로 명시적으로 이동합니다. 장면이 끝났다는 이유만으로 다음 장면으로 자동 이동하지 않습니다. 게임 파일은 [예제](../sianlanggameex1/game.sian)를 참고하세요.
