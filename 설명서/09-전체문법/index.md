# 전체 문법

SianLang 0.3 기준.

주요 형태: type name = expression; var name = expression; name = expression; log(values, sep=..., end=..., flush=...); log.f("{expression}"); def name(a, b=default, #rest) block; if/else if/else; while/repeat/loop ... [else block]; try block catch [name] block; return [expression]; break; continue. 여기서 세미콜론은 설명용 구분이며 실제 코드에는 쓰지 않는다.
