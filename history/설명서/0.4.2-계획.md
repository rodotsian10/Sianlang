# SianLang 0.4.2 개발 및 문법 계획서

이 문서는 SianLang 0.4.2 버전에 반영될 Fjson 데이터 조작 구문 확장 및 식별자 이름 권장사항에 대한 사양서이다.

---

## 1. 개요 (Overview)

SianLang 0.4.2는 Fjson 세이브 데이터 조작 블록의 세부 조작 키워드(`add`, `replace`, `delete`) 파싱 정밀화, 수식/복합 대입 지원, 및 식별자 이름 관련 가이드라인 강화를 목표로 한다.

- **목표 버전**: SianLang 0.4.2
- **주요 확장**:
  1. Fjson 조작 키워드 파싱 연동 (`replace`, `add`, `delete`)
  2. Fjson 복합 대입 및 식 평가 (`+=`, `-=`, `*=`, `/=`)
  3. 변수명 사용 권장사항 명시 (`add`, `replace`, `delete` 식별자 사용 지양)

---

## 2. 상세 문법 및 기능 사양

### 2.1 Fjson 데이터 조작 키워드 (`replace`, `add`, `delete`)

`Fjson` 블록 내에서 JSON 데이터를 직관적으로 조작할 수 있는 전용 문법을 제공한다.

```sian
Fjson "save.json"
    replace j.player.hp = 100
    replace j.player.hp += 50
    add j.inventory = "전설의 검"
    delete j.temp_buff
```

#### 📌 키워드별 역할:
- `replace 키.경로 = 표현식` / `replace 키.경로 += 표현식`: 기존 데이터의 값 대입 및 복합 연산을 수행한다.
- `add 키.경로 = 표현식`: List(배열)에 신규 요소를 추가(`append`)하거나 Dict의 신규 키를 생성한다.
- `delete 키.경로`: 지정한 키 또는 데이터를 삭제한다.

---

### 2.2 식별자 이름 권장사항 (Naming Guidelines)

`add`, `replace`, `delete` 키워드는 파서가 `Fjson` 구문에서 특별하게 해석한다.

- **권장사항**:
  - 일반 함수명이나 `var` 변수명으로 `add`, `replace`, `delete` 단어를 직접 사용하는 것은 문법 파싱 오해 및 구문 모호성 방지를 위해 권장하지 않는다.
  - 변수나 함수 작성 시 `add_item`, `replace_val`, `delete_buff`와 같이 확장된 식별자 사용을 권장한다.
