# SianLang 보관 자료

현재 0.5.1 개발·배포 경로에서 제외한 예전 버전 자료와 일회성 작업 파일을 원래의 상대 경로에 맞춰 보관합니다. 파일을 삭제하지 않았습니다. `dist/`는 정리 대상에서 제외했습니다(검증 빌드가 현재 버전 산출물을 재생성했습니다).

- `설명서/`: 0.4.1·0.4.2·0.5.0 계획서와 과거 개발 순서.
- `docs/`: 초기 게임·rodot 설계안. 현재 사양은 저장소 루트의 `docs/game-api.md`와 `설명서/0.5.1-계획.md`를 보세요.
- `sianlang1stgame/`: 예전 게임 예제. 현재 배포 예제는 루트의 `sianlanggameex1/`입니다.
- `review/`: 0.2 시절 검토 코드·보고서·회귀 입력. `tests/test_runtime.py`가 `review/cases/`를 계속 읽습니다.
- `root-examples/`: 예전 입력·예외 처리 예제. 실행기 회귀 테스트가 계속 사용합니다.
- `tools/`: 현재 빌드에서 호출하지 않는 과거 배포 검증·임시 스크립트.
- `sianlang-vscode/`: 0.1.0~0.5.0의 이전 VSIX 파일(로컬 보관, Git 배포 제외). 현재 0.5.1 VSIX는 원래 위치에 남겼습니다.
- `build/`: 이전 진단용 실행 파일(로컬 보관, Git 배포 제외). 현재 빌드 실행기는 원래 위치에 남겼습니다.
- 그 밖의 루트 파일: 중복 예제, 지난 계획서, 임시 파일. 개인 작업용 임시 파일은 로컬에만 보관합니다.

보관 폴더의 스크립트와 문서는 당시 경로·버전을 그대로 포함할 수 있습니다. 현재 실행 지침으로 사용하지 마세요.
