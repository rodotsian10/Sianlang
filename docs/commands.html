명령어 사전

0.5.1 문법을 명령어별로 정리했습니다. 항목을 클릭하면 예제와 설명을 볼 수 있습니다.

출력과 입력

  • log — 콘솔 출력
  • log.f — 문자열 포매팅 출력
  • input — 터미널 입력

컬렉션과 데이터 조작

  • 자료형과 None
  • 변수 선언과 대입
  • 변환 함수와 len
  • 인덱스 대입 및 컬렉션 메서드
  • 수학 및 난수
  • 파일 I/O
  • Fjson 세이브 데이터 조작

게임과 스프라이트

  • game — 창·FPS·경과 시간
  • scene — 장면·전환
  • key.down — 키 입력
  • draw — 도형·글자
  • rodot — 스프라이트 파일
  • Frodot — 게임 중 데이터 수정
  • collision — 충돌 검사

흐름과 함수

  • if / else
  • while / loop / repeat / else
  • break / continue
  • def와 함수 호출
  • 중첩 함수와 클로저
  • try / catch
