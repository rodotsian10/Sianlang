# SianLang 0.5.0 게임 문법

> 과거 개발안입니다. 0.5.1에서는 `rodot.save(player)`가 제거되고 Frodot이 파일 JSON을 자동 저장합니다. 현재 규칙은 [0.5.1 저장 규칙](0.5.1-계획.md)을 참고하세요.

0.5.0은 Windows x64에서 장면 기반 2D 게임을 만들 수 있는 개발 버전입니다. `.sian`이 장면과 게임 코드를 담당하고, `.rodot`은 PNG 이미지와 JSON 데이터를 한 파일에 담습니다.

## 실행 모델

```sian
game.fps = 60
game.start("play", 640, 480, "My Game")

scene play
    var player = rodot.load("player.rodot")
    var initialized = false
    if initialized == false
        player.x = 100
        initialized = true
    if key.down("right")
        player.x += player.speed * game.delta_time()
    if key.down("q")
        game.close()
```

`game.start`는 창을 열고 지정한 장면을 실행합니다. 장면 본문은 매 프레임 실행됩니다. 장면의 최상위 `var` 선언은 첫 프레임에 변수를 만들고 이후 프레임에는 값을 유지합니다. 일반 대입은 매 프레임 실행되므로 시작 위치처럼 한 번만 정할 값은 조건으로 묶습니다.

장면 이름은 영문 식별자이며 최상위에서 정의합니다. 다음 장면은 자동으로 실행되지 않고 `scene.change("이름")`으로 이동합니다. 같은 장면에 다시 들어가면 새 환경에서 시작합니다.

## 새 명령

| 문법 | 역할 |
| --- | --- |
| `game.fps = N` | 목표 FPS를 1~240에서 정함 |
| `game.start("scene", width, height, "title")` | 게임 창 열기 |
| `game.delta_time()` | 이전 프레임부터 경과한 초 |
| `game.close()` | 게임 종료 |
| `scene name` / `scene.change("name")` | 장면 선언·명시적 전환 |
| `key.down("right")` | 현재 키 입력 확인 |
| `draw.rect/circle/line/text(...)` | 프레임의 도형·문자 그리기 |
| `rodot.create/load/save` | PNG 변환, 스프라이트 불러오기·저장 |
| `Frodot sprite` | 스프라이트 `data` 임시 변경 |
| `collision(a, b)` | 사각형 충돌 검사 |

실제 API 이름은 `rodot.create(png, output)`, `rodot.load(path)`, `rodot.save(sprite[, path])`입니다. `rodot.create`는 기존 출력 파일을 덮어쓰지 않습니다.

## 스프라이트 데이터

`.rodot`의 기본 JSON은 `name`, `meta`(PNG 원본 너비·높이), `data`로 나뉩니다. `name`과 `meta`는 읽기 전용입니다. `data`에는 `visible`, `x`, `y`, `scale`, `rotation`, `opacity`, `layer`, `speed`, `collision`, `user`가 들어 있습니다. `player.x`는 `player.data.x`의 짧은 표기입니다.

`Frodot player` 안에서는 `r.data` 경로에 `replace`, `add`, `delete`를 사용합니다. 직접 대입과 Frodot 모두 메모리의 현재 값을 바꾸며 파일에 자동 저장하지 않습니다. `rodot.save(player)`를 호출해야 파일에 남습니다. VS Code 확장의 Rodot 편집기는 이미지 미리보기와 `data` JSON 편집을 제공합니다.

## 배포 예제

ZIP의 `sianlanggameex1`에 `sprite.png`, `Conversion.sian`, `game.sian`, `README.md`를 넣습니다. 예제 폴더에서 변환 스크립트를 먼저 실행해 `player.rodot`을 만든 뒤 게임을 실행합니다. 방향키로 이동하고 Q로 종료합니다.

## 현재 한계

- 게임 창과 실시간 키 입력은 Windows에서만 사용합니다.
- 충돌은 회전이 반영되지 않는 축 평행 사각형 기준입니다.
- `draw.` 도형·글자는 호출한 프레임에만 표시됩니다.
- `rodot.create`는 기존 `.rodot`을 덮어쓰지 않습니다.

세부 문법은 [게임 API](../docs/game-api.md)와 [명령어 사전](../docs/commands/index.md)을 참고하세요.
