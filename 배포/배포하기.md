# SianLang 배포하기

## 배포 파일 만들기

개발 환경에 GCC, Python 3, Node.js를 준비한 뒤 저장소 루트에서 실행합니다.

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
python tests/test_release.py
```

`dist/0.3.1/`에 ZIP, VSIX, SHA256SUMS.txt, index.html, Sianlangicon.svg가 생성됩니다.
`-SkipTests`는 로컬 개발용입니다. 외부 배포 전에는 기본 명령으로 테스트까지 실행하세요.

## 1. 친구·테스터에게 전달

`SianLang-0.3.1-windows-x64.zip`을 전달하세요. 전체 압축을 해제하고 `START-HERE.md`를 따르면 됩니다.
VS Code만 사용할 사람에게는 VSIX 하나를 전달해도 됩니다.

## 2. GitHub 다운로드

배포할 GitHub 저장소에서 새 Release를 만들고 태그 `v0.3.1`을 사용합니다.
초기 테스트 배포에는 Pre-release를 선택하는 것을 권장합니다.
다음 3개를 Release 첨부 파일로 올리세요.

- `SianLang-0.3.1-windows-x64.zip`
- `sianlang-vscode-0.3.1.vsix`
- `SHA256SUMS.txt`

설명에는 CHANGELOG.md의 0.3.1 항목, 지원 환경 Windows x64, 설치 방법을 적습니다.
저장소는 `https://github.com/rodotsian10/Sianlang`입니다. 릴리스 설명 초안은 `배포/release-notes.md`에 있습니다.

## 3. 소개·다운로드 웹사이트

GitHub Pages 주소는 `https://rodotsian10.github.io/Sianlang/`입니다.
저장소 Settings → Pages에서 **Deploy from a branch / main / docs**를 사용합니다.
빌드하면 `docs/`에 GitHub Release 다운로드 링크가 적용된 사이트가 생성됩니다.
`docs/`를 커밋하고 push하면 Pages가 갱신됩니다. ZIP과 VSIX는 Git에 넣지 않고 Release에 첨부합니다.
`dist/0.3.1/`에는 같은 폴더의 파일을 내려받는 로컬 미리보기 사이트도 함께 생성됩니다.
서버 코드, 외부 폰트, 분석 스크립트는 필요하지 않습니다.

## VS Code Marketplace

VSIX 직접 설치는 바로 가능합니다. 확장 검색으로 설치하려면 별도의 Marketplace 게시가 필요합니다.
현재 manifest의 publisher 값은 `sianlang`이며, 실제로 소유한 게시자 ID인지 확인해야 합니다.
게시 전 소유자 계정을 연결하고 정식 게시 도구의 검사를 통과해야 합니다.
저장소, 실행기 배포 ZIP, VSIX에 MIT 라이선스 원문이 포함됩니다.

공식 안내: [확장 패키징과 게시](https://code.visualstudio.com/api/working-with-extensions/publishing-extension).

## 아이콘

빌드할 때 루트의 `Sianlangicon.svg`를 확장과 사이트에 그대로 복사합니다.
기본 언어 아이콘으로도 등록하므로, 언어 아이콘을 지원하는 기존 테마에서는 자동으로 표시될 수 있습니다.
테마에서 언어 아이콘을 숨기거나 자체 `.sian` 매핑을 지정하면 그 설정이 우선합니다.
확실히 적용하려면 `SianLang File Icons` 테마를 선택합니다.
SVG 안에 글꼴을 사용하는 텍스트가 있으므로 설치된 대체 글꼴에 따라 형태가 조금 달라질 수 있습니다.

공식 안내: [파일 아이콘과 기본 언어 아이콘](https://code.visualstudio.com/api/extension-guides/file-icon-theme).
