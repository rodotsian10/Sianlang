# SianLang 0.4.1 개발 및 문법 계획서

이 문서는 SianLang 0.4.1 버전에 반영될 7가지 핵심 기능 및 신규 문법에 대한 사양서이다.

---

## 1. 개요 (Overview)

SianLang 0.4.1은 게임 데이터 조작, 파일 입출력, 필수 수학/난수 유틸리티 및 직관적인 JSON 파일 편집 구문을 도입하는 것을 목표로 한다.

- **목표 버전**: SianLang 0.4.1
- **주요 확장**:
  1. 컬렉션 인덱스 대입 (`items[0] = value`)
  2. 리스트 조작 메서드 (`append`, `pop`)
  3. 딕셔너리 연산 (`keys`, `values`, `items`)
  4. 문자열 인덱싱 및 UTF-8 순회
  5. 난수 내장 함수 (`random`)
  6. 수학 내장 함수 (`abs`, `min`, `max`, `round`)
  7. 표준 파일 입출력 (`open`) 및 SianLang 전용 JSON 조작 블록 (`Fjson`)

---

## 2. 상세 문법 및 기능 사양

### 2.1 인덱스 대입 (`items[0] = value`, `dict["key"] = value`)

기존의 읽기 전용 인덱싱(`items[0]`)을 가변(Mutable) 인덱싱 대입문으로 확장한다.

```sian
var items = [10, 20, 30]
items[0] = 99

var player = {"name": "Sian", "score": 100}
player["score"] = 200
```

- **타입 검사**:
  - `list` 및 `dict` 타입만 대입을 허용한다.
  - `tuple` 및 `str` 같은 불변(Immutable) 타입에 대입을 시도하면 `RuntimeError`를 발생시킨다.
- **범위 검사**:
  - 리스트 범위를 벗어난 인덱스 대입 시 Index Out of Bounds 오류를 보고한다.

---

### 2.2 리스트 조작 메서드 (`append`, `pop`)

리스트의 동적 크기 확장 및 요소 제거 메서드를 제공한다.

```sian
var inventory = ["검"]
inventory.append("방패") || ["검", "방패"]

var last_item = inventory.pop() || "방패" 반환, inventory는 ["검"]
```

- `append(value)`: 리스트 맨 뒤에 요소를 추가한다.
- `pop()`: 리스트의 마지막 요소를 제거하고 반환한다. 빈 리스트에서 호출하면 오류를 발생시킨다.

---

### 2.3 딕셔너리 연산 (`keys`, `values`, `items`)

딕셔너리의 키, 값, 키-값 튜플 쌍 목록을 반환하며 `for` 순회를 지원한다.

```sian
var user = {"name": "Sian", "hp": 100}

log user.keys()   || ["name", "hp"]
log user.values() || ["Sian", "100"]

for key, val in user.items()
    log key, val
```

---

### 2.4 문자열 인덱싱 및 순회 (`str[i]`, `for char in str`)

문자열을 인덱스로 읽거나 `for` 루프로 순회할 수 있다.

```sian
str name = "시안랭"
log name[0] || "시"

for char in name
    log char
```

- **UTF-8 인코딩 안전성**:
  - 단순 바이트 인덱싱이 아닌 **UTF-8 유니코드 문자(Character) 단위**로 인덱싱 및 순회를 수행하여 한글 깨짐을 방지한다.
  - 문자열은 불변 객체이므로 `name[0] = "A"` 형태의 대입은 허용하지 않는다.

---

### 2.5 난수 내장 유틸리티 (`random`)

게임 제작에 필수적인 정수/실수 난수 및 선택 함수를 제공한다.

```sian
int dice = random.int(1, 6)       || 1 ~ 6 사이의 정수 난수
float rate = random.float()       || 0.0 이상 1.0 미만의 실수 난수
var item = random.choice(items)   || 리스트에서 무작위 1개 원소 추출
```

---

### 2.6 수학 내장 함수 (`abs`, `min`, `max`, `round`)

수식 계산 및 게임 로직 처리를 위한 기본 수학 함수를 제공한다.

```sian
log abs(-10)        || 10
log min(10, 20)     || 10
log max(10, 20)     || 20
log round(3.14159, 2) || 3.14
```

---

### 2.7 파일 입출력

#### A. 표준 파일 입출력 (`open`)
Python 호환 스타일의 표준 파일 핸들 객체를 제공한다.

```sian
var file = open("data.txt", "w")
file.write("hello sianlang\n")
file.close()

var file2 = open("data.txt", "r")
str content = file2.read()
file2.close()
```

- 지원 모드: `"r"` (읽기), `"w"` (쓰기), `"a"` (이어쓰기).

---

#### B. SianLang 전용 JSON 조작 블록 (`Fjson`)

SianLang의 들여쓰기(오프사이드 룰) 철학을 적용한 직관적 JSON 데이터 파일 자동 편집 구문이다.

```sian
int bonus_hp = 50
str default_name = "기사"

Fjson "save_data.json"
    replace player.hp j.player.hp + bonus_hp  || j.접두사: 기존 JSON 데이터 참조
    replace player.name default_name          || 외부 변수로 덮어쓰기
    add player.items "전설의 검"               || 리스트 요소 추가 (배열이 아니면 에러)
    delete player.temp_status                 || 키 삭제
```

##### 📌 `Fjson` 상세 동작 규칙:

1. **파일 로드 및 원자적 자동 저장 (Atomic Write)**:
   - 블록 진입 시 지정된 JSON 파일을 메모리로 자동 파싱하여 로드한다.
   - 들여쓰기 블록(`DEDENT`)이 에러 없이 정상적으로 끝나는 시점에 파일에 완벽히 저장하고 닫는다.
2. **`j.` 접두사 스코프 구분**:
   - `j.키.경로`: JSON 파일 내에 존재하는 **기존 JSON 데이터 값**을 가리킨다.
   - 접두사가 없는 식별자: **SianLang 외부 스코프 변수**를 가리킨다.
   - 이로 인해 변수명 충돌 버그를 100% 방지한다.
3. **명령어 역할 분담**:
   - `replace 키.경로 표현식`: 기존 키의 값을 수식 결과로 **변경/생성**한다.
   - `add 키.경로 값`: 대상 키가 리스트일 때 **새 요소 추가(`append`)** 또는 **신규 키 생성**을 수행한다. (단일 값 키에 `add` 사용 시 런타임 에러 발생)
   - `delete 키.경로`: 해당 키-값 쌍을 **삭제**한다.

## 3. 구현 단계 및 개발 계획 (Roadmap)

1. **Phase 1: 컬렉션 & 문자열 기능 확장**
   - AST `STMT_ASSIGN_INDEX` 추가 및 `items[0] = val` 구현
   - `list.append`, `list.pop`, `dict.keys/values/items` C 런타임 구현
   - UTF-8 유니코드 문자열 인덱싱 및 `for` 루프 대응

2. **Phase 2: 수학 & 난수 내장 함수**
   - `abs`, `min`, `max`, `round`, `random.int/float/choice` C 바인딩 등록

3. **Phase 3: 파일 I/O 및 `Fjson` 블록 엔진**
   - `open()`, `file.read()`, `file.write()`, `file.close()` C 핸들 구축
   - C 기반 경량 JSON 파서/직렬화기 파이프라인 연동
   - Lexer/Parser에 `Fjson`, `replace`, `add`, `delete` 문맥 토큰 및 `j.` 스코프 바인딩 구현
   - `Fjson` 들여쓰기 블록 및 자동 덮어쓰기(Atomic Save) 런타임 구현
