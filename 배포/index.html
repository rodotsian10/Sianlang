SianLang
WINDOWS x64 · v{{version}} · 2D 게임 제작 특화 언어

작은 문법으로
2D 게임을 만드세요.

쉬운 문법과 직관적인 가동성을 갖추고 나만의 게임을 손쉽게 만들 수 있도록 설계된 2D 게임 제작 특화 프로그래밍 언어입니다.

Windows 패키지 다운로드 📖 명령어 사전 보기

ZIP: 실행기 + 확장 + 게임 예제 + Fjson 세이브 예제 + 문법 안내서

str name = "SianLang"
log.f("Hello, {name}!")

Fjson "save.json"
    replace j.player.hp += 10
    add j.inventory = "전설의 검"

VS Code에서 시작하기

  1. VSIX 파일을 다운로드합니다.
  2. VS Code 확장 화면의 … → Install from VSIX...로 설치합니다.
  3. .sian 파일을 저장하고 F6을 누릅니다.

나만의 .sian 아이콘

명령 팔레트에서 Preferences: File Icon Theme → SianLang File Icons를 선택하세요.

파일 아이콘 테마는 한 번에 하나만 선택할 수 있습니다.

이번 버전(v{{version}}) 주요 기능

Fjson 세이브 데이터 조작 블록(replace·add·delete), 컬렉션(list·tuple·dict), 인덱스 대입, list/dict 메서드, UTF-8 문자열 인덱싱 및 순회, 수학/난수 내장함수, 파일 입출력(open/read/write/close), try/catch 예외처리를 지원합니다. 향후 2D 게임 전용 창 및 실시간 키 입력 기능이 탑재될 예정입니다.

배포 파일 확인: SHA-256 체크섬 · 개발 중인 언어이며 실행 파일은 아직 서명되지 않았습니다.
