# draw: 도형과 글자 그리기

모든 직접 그리기 명령은 `draw.`으로 시작합니다.

```sian
draw.rect(10, 10, 100, 50, "#ff0000")
draw.circle(200, 100, 25, "#00ff00")
draw.line(0, 0, 300, 200, "#ffffff")
draw.text("Hello", 20, 20, "#ffffff")
```

인수는 순서대로 다음과 같습니다.

- `draw.rect(x, y, 너비, 높이 [, 색])`
- `draw.circle(중심_x, 중심_y, 반지름 [, 색])`
- `draw.line(x1, y1, x2, y2 [, 색])`
- `draw.text(문자열, x, y [, 색])`

색은 `#RRGGBB` 형식이며 생략하면 흰색입니다. 이 명령은 호출한 프레임에만 적용됩니다. 장면이 매 프레임 다시 실행되므로 화면에 계속 보이게 하려면 장면 코드에서 호출합니다. `.rodot` 스프라이트는 별도 `draw.` 명령 없이 자동으로 그려집니다.
