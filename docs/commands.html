명령어 사전

0.4.1에서 실제로 동작하는 문법입니다. 문서를 클릭하면 GitHub에서 자세한 예제와 설명을 볼 수 있습니다.

출력과 입력

  • log — 콘솔 출력
  • log.f — 문자열 포매팅 출력
  • input — 터미널 입력

컬렉션과 내장 기능

  • 자료형과 None
  • 변수 선언과 대입
  • 변환 함수와 len
  • 인덱스 대입 및 컬렉션 메서드 (append, pop, keys, values, items)
  • 수학 및 난수 (abs, min, max, round, random.*)
  • 파일 I/O (open, read, write, close)

흐름과 함수

  • if / else
  • while / loop / repeat / else
  • break / continue
  • def와 함수 호출
  • 중첩 함수와 클로저
  • try / catch

기초 문법

  • 연산자
  • 주석

게임 기능은 게임 기능 계획에서 확인하세요.
