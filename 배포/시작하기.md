# SianLang 0.3.1 시작하기

Windows 10/11 x64용 첫 배포판입니다. 언어 기능은 계속 발전 중입니다.
사용자는 Python, GCC, Node.js를 설치할 필요가 없습니다.

## VS Code에서 사용하기 — 권장

1. 다운로드한 ZIP을 원하는 폴더에 모두 압축 해제합니다.
2. VS Code의 확장 화면에서 `…` → **Install from VSIX...**를 선택합니다.
3. `sianlang-vscode-0.3.1.vsix`를 선택합니다.
4. `examples/hello.sian`을 열고 오른쪽 위 **▶ 실행 버튼**을 누릅니다. F6도 같은 기능입니다.
5. 출력은 터미널에 표시됩니다. `input()`도 터미널에서 입력합니다. 실행 중지는 **Ctrl+C**입니다.

VSIX 파일 하나만 전달해 설치해도 실행기가 포함되어 있어 작동합니다.
실행 전 파일을 저장하고 본인이 신뢰하는 코드가 있는 작업 공간을 신뢰 상태로 열어 주세요.

## .sian 아이콘

VS Code에서 **Preferences: File Icon Theme** 명령을 실행하고 **SianLang File Icons**를 선택합니다.
`.sian` 파일에 제작자가 제공한 `Sianlangicon.svg`가 표시됩니다.
VS Code는 한 번에 파일 아이콘 테마 하나를 적용합니다. 이 테마를 선택하면 기존 Material Icon Theme를 대체합니다.
기본 언어 아이콘도 등록되어 있어 기존 테마가 언어 아이콘을 허용하면 테마를 바꾸지 않아도 표시됩니다.
Material Icon Theme 등에서 언어 아이콘을 숨기는 경우에는 이 기본 아이콘이 표시되지 않을 수 있습니다.

## 콘솔에서 사용하기

압축 해제한 폴더에서 PowerShell을 열고 실행합니다.

```powershell
.\Sianlang.exe --version
.\Sianlang.exe .\examples\hello.sian
.\Sianlang.exe .\examples\features-demo.sian
```

실행 파일만 더블클릭하면 편집기가 열리는 프로그램은 아닙니다. 실행할 `.sian` 파일을 인수로 전달합니다.
폴더와 파일 이름에 한글·공백을 사용할 수 있습니다.

## 첫 프로그램

```sian
str name = "SianLang"
log.f("Hello, {name}!")
```

문법 전체는 `docs/grammar.md`, 아직 계획 중인 게임 기능은 `docs/game-roadmap.md`를 참고하세요.
`log`는 콘솔 출력이며 파일 출력과 실시간 키 입력, 게임 창은 아직 제공하지 않습니다.

## 문제 해결

- 이전 실행기 경로를 설정했다면 VS Code 설정 `sianlang.executable`을 빈 문자열로 바꾸면 포함된 실행기를 사용합니다.
- macOS/Linux/WSL/SSH 원격 환경에는 실행기가 포함되지 않습니다. 해당 환경의 실행기를 별도로 빌드하고 `sianlang.executable`에 지정해야 합니다. 이번 배포 검증 대상은 Windows x64입니다.
- 자동 완성은 문법 스니펫 수준입니다. 언어 서버 기반 진단·정의 이동·디버거는 아직 없습니다.
- 실행 파일과 VSIX는 코드 서명이 되어 있지 않습니다. 배포된 SHA256SUMS.txt와 파일 출처를 확인하세요.
